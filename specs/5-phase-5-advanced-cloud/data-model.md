# Data Model: Phase 5 Advanced Cloud

This model reflects the distributed state managed via Dapr State Store.

## Entities

### Task (Domain: Task Service)
- **ID**: UUID (Key in Dapr State Store)
- **Content**: String
- **Status**: Enum (TODO, IN_PROGRESS, COMPLETED)
- **UserID**: String (Google Sub ID)
- **CreatedAt**: ISO8601
- **UpdatedAt**: ISO8601

### Reminder (Domain: Reminder Service)
- **ID**: UUID
- **TaskID**: UUID
- **TriggerTime**: ISO8601
- **Status**: Enum (SCHEDULED, TRIGGERED, CANCELLED)

### RecurringDefinition (Domain: Recurring Task Service)
- **ID**: UUID
- **TemplateContent**: String
- **Schedule**: Cron String (e.g., `0 0 * * *`)
- **UserID**: String
- **LastGeneratedAt**: ISO8601

### ActivityRecord (Domain: Audit Service)
- **ID**: UUID (Auto-generated by Audit Service)
- **EventType**: String (e.g., `TaskCreated`)
- **Payload**: JSON Object
- **CreatedAt**: ISO8601

## State Management
- **Store Name**: `taskpilot-state`
- **Keys**: Prefixed by service name (e.g., `task:uuid`, `reminder:uuid`)
- **Consistency**: Eventual consistency via Pub/Sub for Audit Service.
