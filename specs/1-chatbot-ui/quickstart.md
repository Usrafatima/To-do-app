# Quickstart: Chatbot Frontend UI

This document provides instructions for running the frontend application to test the chatbot UI feature.

## Prerequisites

- Node.js (version specified in project's `.nvmrc` or `package.json`)
- `npm` or `yarn` installed

## Running the Application

1.  **Navigate to the frontend directory**:
    ```bash
    cd frontend
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    ```

4.  **Access the application**:
    Open your web browser and navigate to `http://localhost:3000`.

5.  **View the Chatbot**:
    The chatbot launcher button will be visible in the bottom-right corner of the screen. Click it to open the chat interface.
